# 第一版双相机视觉方案

## 已确定的范围

- PCB 使用夹具固定，放板方向与大致位置已知，贴装过程中保持不动。
- 下视相机（down_looking）：随贴装头移动，向下拍 PCB Mark 和料位。
- 上视相机（up_looking）：固定在工作台，向上拍吸嘴吸取后的元件。
- 第一版不配置整板全局相机，不引入 YOLO 整板检测。
- 上位机 console 面板负责制板文件处理与任务准备，向 controller 提供元件坐标、板外形、Mark 设计坐标与任务配置；面板 Go 后端尚未实现。
- Linux 板运行纯 Python 后台，承担视觉、任务编排与下位机通信。

两个相机角色按观看方向命名，不按安装位置叫“上相机/下相机”。
实体相机应使用设备唯一标识或固定端口绑定角色，不仅依赖可能变化的 /dev/video0 顺序。

## PCB 定位流程

1. PCB 夹紧，确认回零与设备状态。
2. 根据夹具位置和板上 Mark 的设计坐标，计算预计拍照位置。
3. 抬升到允许横移的高度，将下视相机移到对应区域，等待运动完成与有效新帧。
4. 按 Mark 配方筛选候选、测量圆心，转换为机器坐标。
5. 测量至少两个已正确对应、相距足够远的 Mark，求 PCB 平移和旋转。
6. 使用额外 Mark（如果有）检查残差；验证通过才允许开始贴装。

圆形 Mark 本身没有可识别朝向，不能依靠一个圆心确定板旋转。
未找到 Mark 时使用有边界、有次数限制的搜索或暂停，不自动把任意圆形候选当作 Mark。
板厚、工作高度和对应板面必须在标定/任务配置中明确。

## 元件定位流程

1. 供料、取料、抬升，按实际传感器能力检查吸取。
2. 将吸嘴移到固定上视相机的标定拍照位置和高度。
3. 获取有效图像，按封装配方测量元件中心、角度与可用方向特征。
4. 将结果换算为元件相对吸嘴旋转轴的偏移。
5. 结合 PCB 对位、目标贴装角度和吸嘴标定，求最终运动目标。
6. 执行旋转、移动和贴装，并记录结果。

旋转吸嘴会改变偏心向量方向，不能直接沿用拍照时的 XY 偏差。
对称外形可能存在 90°/180°方向歧义；极性要由额外特征或已验证的供料方向确定。
识别失败、结果不确定或标定缺失时，不生成猜测的贴装坐标。

## 代码边界与当前实现

| 模块 | 职责 | 当前状态 |
| --- | --- | --- |
| common.cameras | 两种相机角色 | 已实现 |
| ports.camera / Frame | 帧编号与相机来源 | 已实现 |
| vision.models / Detection | 结果关联相机和帧 | 已实现 |
| jobs.workflow | 按角色选择相机并核对结果来源 | 仅模拟单次定位 |
| vision/pipelines | Mark、元件各自的识别流水线 | 待实现 |
| calibration | 下视映射、PCB 对位、上视与吸嘴旋转偏移 | 待实现 |
| machine / adapters | 取料、IO、实际运动、停止与恢复 | 真实能力待实现 |

模拟应用组装两只相机，默认 --demo 只运行一次下视模拟定位。
模拟上视检测没有真实吸取动作，返回的图像和定位结果均为合成数据。
相机角色加帧编号只防止两路结果混淆，不能替代任务编号、时序与标定版本校验。

## 实施顺序

先采集两路真实图片，分别验证 Mark 与元件定位；再做标定；随后接下位机并跑单次取放。
USB 带宽、曝光、光源、识别耗时及重复定位误差在最终板卡和相机组合上实测。
