# 通信协议

此目录是跨模块协议约定的唯一来源。

已实现：[局域网发现与连接 v1](lan-connection-v1.md)，使用 mDNS 发现、TCP JSON Lines 长连接，
支持握手、心跳及只读状态查询。以下业务协议仍待确定。

## 笔记本与 Linux 控制板

- 设备状态与坐标字段、长度及角度单位。
- 点动、回零、真空、任务启动/暂停/停止等操作接口。
- 状态事件、任务数据与业务错误格式；基础连接协议见上述 v1 文档。
- 重复请求识别、控制权和断线后的处理方式。

## Linux 控制板与下位机

- 物理通信接口、帧格式、命令编号与协议版本。
- 单位、坐标方向、绝对/相对位置和速度含义。
- 命令接收确认、执行完成、失败与设备状态回复。
- 超时、重复报文、重连、停止和重启后的状态确认。

协议确定后，在此保存说明、报文样例及必要的机器可读定义。不能将“收到命令”当作“电机已完成运动”。
